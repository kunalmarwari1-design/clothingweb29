# MenStyle - Premium Male Clothing Store

A fully functional online clothing e-commerce website specializing in men's fashion.

## Features

✨ **Product Catalog**
- Browse a wide selection of men's clothing
- Filter by category, price, and size
- Sort by price, newest, and featured

🛒 **Shopping Cart**
- Add items to cart with size selection
- Update quantities
- Remove items
- Real-time cart updates

💳 **Checkout System**
- Secure checkout process
- Billing and payment information forms
- Order summary
- Tax and shipping calculation

📱 **Responsive Design**
- Mobile-friendly interface
- Works on all devices
- Smooth user experience

🎨 **Modern UI**
- Clean and professional design
- Smooth transitions and animations
- Intuitive navigation

## How to Use

1. **Browse Products**
   - Visit the Shop page to see all products
   - Use filters to narrow down choices
   - Sort products by price or newness

2. **Add to Cart**
   - Select a size from the product card
   - Click "Add to Cart"
   - Continue shopping or proceed to checkout

3. **Manage Cart**
   - View all items in your cart
   - Update quantities
   - Remove unwanted items
   - See real-time totals

4. **Checkout**
   - Enter billing and delivery information
   - Add payment details
   - Complete your purchase

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1a1a2e;
    --secondary-color: #0f3460;
    --accent-color: #e94560;
}
```

### Products
Edit the `products` array in `script.js` to add, remove, or modify products.

### Prices
Update product prices in the `products` array in `script.js`.
